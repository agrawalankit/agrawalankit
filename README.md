- **15+ years** building software products and solving real-world technology problems

## My approach

**Understand the business problem** → **diagnose the technical constraint** → **choose the right solution** → **execute** → **optimize**

I don't believe every problem needs a rewrite, more infrastructure or the newest technology. Sometimes the answer is better architecture. Sometimes it's a better query. Sometimes it's removing technical debt. And sometimes it's building less.
